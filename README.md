# Проект 22 Знакомство с Django
## Описание проекта

**Интернет-магазин** — это учебный проект на Django, 
реализующий базовую структуру сайта с каталогом товаров и страницей контактов.  

## Функционал на текущий момент

- Главная страница (`/` или `/home/`)
- Страница с контактной информацией (`/contacts/`)
- Использование шаблонов с Bootstrap для стилизации
- Приложение `catalog` с собственной маршрутизацией

## Базовые настройки проекта
В проекте есть файл с зависимостями.
Создан Django-проект.
Создано приложение fcatalog .
Приложение catalog зарегистрировано в INSTALLED_APPS .
Создан файл urls.py в приложении catalog.
## Разработка функциональности проекта
Создан HTML-шаблон главной страницы.
Элементы в шаблонах расположены упорядоченно.
Стили в шаблонах отображаются корректно.
Контроллер рендерит шаблон главной страницы функцией render.
Контроллер рендерит шаблон страницы контактов функцией render .
В контроллерах корректно указаны пути к шаблонам.
Контроллер главной страницы зарегистрирован на адрес / или home/ .
Контроллер страницы контактов зарегистрирован на адрес contacts/ .
В основном URL-файле использован include для подключения URL-файла приложения catalog .
Все URL-адреса в проекте заканчиваются на / .

# 23 Работа с ORM в Django

## Описание проекта
Данный проект реализует базовые модели для интернет-магазина: Продукты и Категории. 
Проект включает работу с медиаданными, настройку административной панели, работу через shell, 
а также загрузку данных через фикстуры и кастомные команды

## Содержание
+ Модели
+ Работа с медиаданными
+ Админка
+ Работа через shell
+ Фикстуры и кастомные команды

# Модели
+ Модель продукта
Содержит необходимые поля (например: название, описание, цена, изображение, категория и т.д.).
+ Модель категории
Содержит необходимые поля (например: название, описание и т.д.).
+ В обоих моделях определён класс Meta с параметрами verbose_name и verbose_name_plural.
+ В моделях реализован метод __str__ для удобного отображения объектов.
+ Модель продукта связана с категорией через ForeignKey.
+ Миграции созданы и применены.

## Работа с медиаданными
+ В настройках проекта корректно указаны:
    MEDIA_URL
    MEDIA_ROOT
+ В режиме дебага настроены URL для отображения медиаданных.
+ Установлен и зафиксирован пакет Pillow для работы с изображениями.

## Админка
Для продуктов и категорий настроено корректное отображение в административной панели Django:
+ Выводятся основные поля.
+ Отображаются связанные данные.

## Работа через shell
Установлен и зафиксирован пакет ipython для удобной работы в shell.
Примеры выполненных действий:
+ Создание категорий и продуктов через ORM-запросы (create()).
+ Получение всех категорий и продуктов.
+ Получение всех продуктов определенной категории.
+ Обновление цены продукта.
+ Удаление продукта.

## Фикстуры и кастомные команды
+ Фикстуры для продуктов и категорий сформированы и корректно загружаются через команду loaddata.
+ Не возникает проблем с кодировкой данных.
  + Реализована кастомная команда для загрузки объектов:
  Перед загрузкой происходит предварительное удаление старых данных.
  Используются существующие фикстуры.
  Связи между продуктами и категориями выстраиваются корректно.

# 24 Шаблонизация
Описание
В данном этапе реализована система шаблонов для интернет-магазина, 
добавлена страница отдельного товара, 
а также внедрён базовый шаблон и подшаблон главного меню для повторного использования кода.


## Страница одного товара
+ Создан новый контроллер для отображения одного товара.
+ Контроллер принимает параметр pk (идентификатор товара).
+ Контроллер получает объект товара из базы данных с помощью ORM-запроса.
+ Контроллер рендерит отдельный шаблон страницы товара.
+ Создан отдельный шаблон для одного товара.
+ В шаблоне отображаются все данные об объекте (название, описание, цена, изображение, категория и т.д.).
+ Изображение товара выводится корректно.
+ Контроллер зарегистрирован на URL с корректным неймингом (например, /product/<pk>/).

## Главная страница
+ В контроллер главной страницы добавлен ORM-запрос для получения списка всех продуктов.
+ В шаблоне главной страницы отображаются только необходимые данные о каждом товаре: изображение, имя, сокращённое описание.
+ Описание товара на главной странице сокращено до 100 символов.
+ С главной страницы можно перейти на страницу отдельного товара и вернуться обратно.
+ Изображения товаров на главной странице выводятся корректно.

## Базовый шаблон
+ Выделен базовый шаблон (base.html), содержащий общий HTML-код для всех страниц.
+ В базовый шаблон вынесены повторяющиеся элементы (шапка, футер, подключение стилей и т.д.).
+ Базовый шаблон используется в шаблонах главной страницы, страницы контактов и страницы одного товара.

## Подшаблон главного меню
+ Создан отдельный подшаблон для главного меню (_main_menu.html).
+ Подшаблон главного меню подключается во все основные шаблоны (главная страница, контакты, страница товара).
